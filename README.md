# VOLTERRA — Play Hard. Move Faster.
React + Vite + Tailwind 3 + React Router + Lucide. Fully client-side.
```
npm install
npm run dev
```
Routes: `/`, `/shop` (`?category=football`, `?type=Footwear`, `?sale=1`, `?sort=newest`, `?q=`), `/product/:id`, `/about`.
Images load from Unsplash; each has a styled fallback if offline.
